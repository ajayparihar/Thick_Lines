Thick Lines - Help & Keyboard Shortcuts

Getting Started

  • Select a tool (Pen or Eraser) from the toolbar
  • Choose your color by clicking color buttons or pressing 1-4
  • Adjust brush/eraser size using the sliders
  • Click and drag on the canvas to draw

Accessibility Features

  • Full keyboard navigation with Tab and arrow keys
  • Screen reader support with live announcements
  • High contrast mode for better visibility
  • Customizable brush and eraser sizes
  • Clear visual feedback for all actions

Mobile & Touch Gestures

  • Single finger: Draw with selected tool
  • Two fingers pinch: Zoom in/out (50%-300%)
  • Ctrl+0: Reset zoom to 100%
  • Optimized touch targets for easier interaction

Export Options

  • Multiple format support (PNG, JPEG)
  • Quality adjustment for file size control
  • Multiple resolution options (Original, HD, 4K)
  • Transparent background preservation in PNG
