# Thick Lines - Drawing Tool

A modern, accessible HTML5 drawing application with advanced features including multiple export formats, canvas resizing, mobile touch support with pinch-to-zoom, and comprehensive accessibility features.

## Features

- **Drawing Tools**: Pen and eraser with adjustable sizes
- **Color Palette**: Red, Green, Blue, and Yellow colors with keyboard shortcuts (1-4)
- **Export Options**: PNG and JPEG formats with quality control and multiple resolutions
- **Canvas Management**: Resizable canvas with preset and custom dimensions
- **Mobile Support**: Touch-optimized with pinch-to-zoom functionality
- **Accessibility**: Full keyboard navigation, screen reader support, and high contrast mode
- **Advanced Features**: Undo/redo, theme toggle, and comprehensive help system

## Usage

Simply open `index.html` in a modern web browser. No installation or build process required.

## Keyboard Shortcuts

- **1-4**: Select colors (Red, Green, Blue, Yellow)
- **P**: Pen tool
- **E**: Eraser tool
- **Ctrl+Z**: Undo
- **Ctrl+Y**: Redo
- **Ctrl+S**: Export drawing
- **Ctrl+0**: Reset zoom
- **T**: Toggle theme
- **C**: Toggle contrast
- **?**: Show help

## Mobile Gestures

- **Single finger**: Draw
- **Two fingers**: Pinch to zoom (50%-300%)

## Browser Compatibility

Requires a modern browser with HTML5 Canvas support.
